## Prerequisites

- Node.js 24+
- pnpm 11

## Install

```bash
pnpm install
pnpm setup
pnpm dev
```

| Surface   | URL                   |
| --------- | --------------------- |
| App (web) | http://localhost:8081 |
| API       | http://localhost:8787 |
| Docs      | http://localhost:4321 |
